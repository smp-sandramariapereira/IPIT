# Exemplo fictício preenchido — CompartilhaEsporte

Este exemplo mostra como uma equipe poderia documentar um Micro-Ideathon. **O projeto, a escola, as pessoas e os resultados são fictícios** e existem apenas para fins formativos.

## Situação proposta

Durante os intervalos, estudantes têm dificuldade para localizar e solicitar materiais esportivos disponíveis para empréstimo. A equipe propõe um fluxo simples de consulta e reserva chamado **CompartilhaEsporte**.

## Como usar

- apresente o exemplo somente depois que as equipes produzirem suas primeiras ideias, para evitar cópia;
- compare a relação entre problema, evidência, solução e protótipo;
- destaque que uma documentação honesta inclui limitações e próximos testes;
- adapte a profundidade ao tempo e à faixa etária.

> Este exemplo não representa evidência da experiência de origem do IPIT.
