# 🎁 Recursos gratuitos do IPIT

Esta pasta reúne materiais introdutórios para professores e equipes conhecerem a metodologia.

## 📦 Materiais previstos

- 🧭 infográfico das oito etapas;
- ✅ checklist de preparação;
- 🔍 canvas de definição do problema;
- 💡 canvas de proposta de valor;
- 📊 rubrica resumida;
- 🎤 roteiro de pitch;
- 📝 modelo de README para projetos estudantis.

## ⚖️ Uso responsável

Os materiais devem preservar autoria, privacidade, acessibilidade e proteção de dados. Fotografias, nomes e produções de estudantes só devem ser publicados com autorização adequada.
