# 🚀 IPIT — Ideathon Pedagógico de Inovação Tecnológica

> **Da ideia ao MVP:** uma metodologia educacional para transformar problemas reais em soluções criadas por estudantes.

O **IPIT** orienta professores, escolas e cursos técnicos na realização de jornadas de inovação pedagógica. A proposta integra aprendizagem baseada em projetos, Design Thinking, cultura maker, metodologias ágeis, GitHub, Inteligência Artificial, prototipação e desenvolvimento de Produtos Mínimos Viáveis.

## 🔄 As oito etapas

```mermaid
flowchart LR
    A[🔍 Descoberta] --> B[💡 Ideação]
    B --> C[🧩 Solução]
    C --> D[⚙️ Tecnologia]
    D --> E[🚀 MVP]
    E --> F[🏗️ Arquitetura]
    F --> G[💻 Desenvolvimento]
    G --> H[🎤 Pitch]
```

## 🎯 Princípio central

Cada etapa termina com um **entregável verificável**. O avanço depende das evidências produzidas no processo, e não apenas da participação.
