# 🎁 Kit Gratuito IPIT

**Autora:** Sandra Maria Pereira  
**Metodologia:** IPIT — Ideathon Pedagógico de Inovação Tecnológica

Este kit reúne materiais introdutórios para professores, escolas e cursos técnicos que desejam experimentar a metodologia IPIT em pequena escala.

> 🎯 **Objetivo do kit:** permitir a realização de um primeiro Micro-Ideathon com segurança pedagógica, clareza metodológica e registros mínimos do processo.

## 📦 Materiais disponíveis

| Material | Finalidade |
|---|---|
| [✅ Checklist inicial](01-checklist-inicial.md) | Verificar condições pedagógicas, técnicas e institucionais |
| [🔎 Canvas do problema](02-canvas-problema.md) | Investigar e delimitar um desafio autêntico |
| [💡 Canvas da proposta de valor](03-canvas-proposta-de-valor.md) | Relacionar problema, público e solução |
| [🎤 Roteiro de pitch](04-roteiro-pitch.md) | Organizar a apresentação final da equipe |
| [📊 Rubrica resumida](05-rubrica-resumida.md) | Avaliar processo, produto e comunicação |
| [🚀 Guia do Micro-Ideathon](06-guia-micro-ideathon.md) | Realizar uma aplicação inicial em um turno |
| [🤖 Guia de uso responsável de IA](07-guia-uso-responsavel-ia.md) | Orientar autoria, validação e segurança |

## 🧭 Percurso sugerido

```mermaid
flowchart LR
    A[✅ Preparar] --> B[🔎 Investigar]
    B --> C[💡 Idear]
    C --> D[🧩 Prototipar]
    D --> E[🎤 Apresentar]
    E --> F[📊 Avaliar]
```

## 🏫 Como utilizar

1. Leia o checklist e defina o desafio.
2. Organize equipes pequenas.
3. Use os canvases para orientar pesquisa e ideação.
4. Solicite um protótipo de baixa fidelidade.
5. Finalize com pitch e feedback.
6. Registre aprendizados e próximos passos.
