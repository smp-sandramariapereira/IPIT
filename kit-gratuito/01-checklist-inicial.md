# ✅ Checklist inicial para aplicar o IPIT

**Autora:** Sandra Maria Pereira  
**Metodologia:** IPIT — Ideathon Pedagógico de Inovação Tecnológica

Use este checklist antes de iniciar a atividade. Marque cada item como concluído, pendente ou não aplicável.

## 🎯 1. Intencionalidade pedagógica

- [ ] O desafio está relacionado ao currículo.
- [ ] Os objetivos de aprendizagem foram definidos.
- [ ] Os estudantes compreenderão por que realizarão a atividade.
- [ ] O produto esperado é compatível com o tempo disponível.
- [ ] A avaliação será apresentada antes do início.

## 🔎 2. Problema e contexto

- [ ] O desafio parte de uma necessidade real da escola ou da comunidade.
- [ ] O problema está formulado sem antecipar uma solução.
- [ ] Há um público ou usuário identificável.
- [ ] Existem fontes, dados, relatos ou observações que podem apoiar a investigação.
- [ ] O tema é adequado à faixa etária e ao contexto da turma.

## 👥 3. Equipes

- [ ] As equipes têm tamanho adequado, preferencialmente entre 3 e 5 integrantes.
- [ ] Há diversidade de habilidades nos grupos.
- [ ] Os papéis iniciais foram combinados.
- [ ] O acordo de equipe será preenchido.
- [ ] Todos terão oportunidade real de participação.

## 🕒 4. Tempo e cronograma

- [ ] A duração foi definida.
- [ ] As etapas cabem no período disponível.
- [ ] Há tempo para pesquisa, ideação, prototipação e apresentação.
- [ ] Foram previstos intervalos ou mudanças de atividade.
- [ ] Existe margem para atrasos e ajustes.

## 💻 5. Recursos e infraestrutura

- [ ] O espaço está reservado.
- [ ] Os equipamentos foram testados.
- [ ] A conexão com a internet foi verificada.
- [ ] Há alternativa offline.
- [ ] Os materiais físicos estão disponíveis: papel, canetas, notas adesivas e fita.
- [ ] As ferramentas digitais foram autorizadas pela instituição.

## 🤖 6. Inteligência Artificial

- [ ] A turma recebeu orientação sobre uso responsável de IA.
- [ ] Os estudantes sabem que precisam revisar e testar as respostas.
- [ ] Foi definido como registrar o uso de IA.
- [ ] Dados pessoais, senhas e informações sensíveis não serão inseridos nas ferramentas.
- [ ] A autoria final continuará sendo da equipe.

## 🔐 7. Segurança, privacidade e acessibilidade

- [ ] O projeto evita a exposição de dados pessoais.
- [ ] As imagens e registros possuem autorização de uso.
- [ ] O repositório não conterá senhas ou chaves de acesso.
- [ ] Os materiais são acessíveis aos estudantes participantes.
- [ ] Foram previstas adaptações para necessidades específicas.

## 📊 8. Avaliação e evidências

- [ ] A rubrica está pronta.
- [ ] Cada etapa possui um entregável.
- [ ] O diário de bordo será utilizado.
- [ ] O professor definiu como oferecerá feedback.
- [ ] A equipe fará uma retrospectiva ao final.

## 🤝 9. Apoio institucional

- [ ] A gestão conhece a proposta.
- [ ] Os horários e espaços foram alinhados.
- [ ] Os profissionais envolvidos sabem suas responsabilidades.
- [ ] Parceiros ou convidados receberam orientações pedagógicas.
- [ ] A banca de avaliação foi definida, quando aplicável.
